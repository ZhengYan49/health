# health

个人健康与健身管理项目。

## 目标

- 记录体重、围度、训练、饮食和睡眠
- 管理阶段性的减脂与力量训练计划
- 通过数据复盘调整计划，而不是依赖短期体重波动

## 目录

```text
docs/       计划、身体数据、复盘结论和长期记录
data/       本地记录数据（不要提交敏感健康信息）
scripts/    数据整理或分析脚本
```

从 [docs/README.md](docs/README.md) 开始查看记录体系。

## 隐私提醒

本仓库是公开仓库。请不要提交身份证明、病历、体检报告、联系方式，或任何不希望公开的体重、血压和身体成分数据。个人数据建议保存在本地未跟踪文件中。

## 当前状态

已完成健身计划与身体变化记录的初始文档结构，暂未绑定具体技术栈。后续可根据需要扩展为记录工具、数据分析脚本或健康计划应用。
