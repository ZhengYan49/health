# 阶段性结论

最后更新：2026-09-21

本文件只保留有数据支持、对下一阶段有用的判断。新证据出现后，应更新原结论，而不是简单堆叠相互矛盾的判断。

## 当前结论

### 1. 目前的减重方案短期内有效且主观耐受良好

- 证据：体重约一个月从91 kg降到85 kg，共下降6 kg。
- 证据：用户反馈没有明显疲劳和饥饿感。
- 判断：当前训练和饮食至少在短期内能够执行；暂时不需要因为“不累”而主动增加训练量。

### 2. 早期减重速度偏快，不能把全部变化当成脂肪减少

- 证据：约4周下降6 kg，按简单平均约1.5 kg/周。
- 判断：其中可能包含水分和糖原变化。后续目标改为每周约0.3–0.7 kg，并用7天平均体重和腰围判断趋势。

### 3. 1731 kcal 更适合作为估算参考，不作为“代谢好坏”的评分

- 证据：基础代谢数值一个月没有变化，且来源和测量方式未确认。
- 判断：体脂秤或软件的基础代谢值通常是估算值；后续更关注总摄入、体重趋势、腰围、力量和恢复情况。

### 4. 不续健身课后，保留力量训练是首要任务

- 证据：计划从课程训练转为自主训练。
- 判断：每周3次全身力量训练，用动作质量和渐进加重维持训练刺激；有氧和步数作为辅助，不用通过无限增加有氧来弥补不续课。
