# 健身长期记录

这里保存健身计划、身体变化、每周复盘和阶段性结论。

## 文档职责

- [fitness-plan.md](fitness-plan.md)：当前执行中的减脂与训练计划
- [body-metrics.md](body-metrics.md)：已经确认的身体数据和变化
- [weekly-check-in.md](weekly-check-in.md)：每周复盘时填写的模板
- [conclusions.md](conclusions.md)：根据记录得出的结论、证据和下一步调整

## 更新规则

1. 先记录事实，再写结论；估算值要标明“估算”。
2. 体重使用晨起、如厕后、训练前的测量值；判断趋势使用7天平均值，不根据单日波动下结论。
3. 每周至少记录一次：体重、腰围、训练完成情况、睡眠、饥饿感和疲劳感。
4. 只有连续2–4周的数据支持同一个趋势时，才调整热量或训练量。
5. 任何疼痛、疾病、用药或异常症状不做自我诊断，必要时交给医生判断。

## 隐私

GitHub 仓库是公开的。这里目前只记录你明确提供并要求保存的健身数据；不要继续提交病历、检查报告、联系方式或其他不希望公开的信息。
